🌽 AI-Climate-Early-Warning-System

An AI-Enabled Early Warning and Decision-Support System for Climate-Smart Maize Production in Tanzania

1. Project Overview

The AI-Climate-Early-Warning-System is an AI-enabled digital platform developed to support climate-smart maize production in Tanzania.

The platform integrates weather and climate information, machine learning approaches, and agricultural risk assessment to provide timely weather insights, early warnings, and decision-support information to farmers, agricultural extension officers, policymakers, and system administrators.

The system aims to bridge the gap between climate information and practical agricultural decision-making by translating environmental data into accessible and actionable information.

2. Problem Statement

Climate variability and weather-related agricultural risks present significant challenges to maize production in Tanzania. Farmers and agricultural stakeholders need accessible, timely, and location-relevant climate information to make informed decisions.

This project addresses this challenge through an integrated digital platform that combines weather monitoring, predictive analytics, and agricultural risk assessment to support informed decision-making.

3. Project Objectives

- Integrate weather and climate information from multiple data sources.
- Apply machine learning techniques for agricultural prediction and risk assessment.
- Provide early warnings on weather-related agricultural risks.
- Support Fall Armyworm (FAW) risk assessment.
- Deliver accessible and actionable agricultural information through a user-friendly digital platform.
- Support evidence-informed agricultural planning and decision-making.

4. Key System Features

- Weather Monitoring: Access to weather information, including temperature, rainfall, and humidity.
- Predictive Analytics: Application of machine learning approaches for agricultural risk assessment.
- Fall Armyworm Risk Assessment: Classification of FAW risk into Low, Medium, and High categories.
- Planting Advisory: Weather-informed planting guidance.
- Regional Monitoring: Monitoring of agricultural weather records across selected regions.
- Early Warning Information: Communication of agricultural risk information.
- Role-Based Access: Dedicated dashboards for different categories of users.
- Bilingual Interface: English and Kiswahili language options.

 5. System Architecture and User Modules

The platform incorporates four main user modules:

 5.1 Farmer Dashboard

Provides farmers with accessible weather information, planting advisories, and agricultural risk information to support farm-level decision-making.

5.2 Agricultural Extension Officer Dashboard

Enables extension officers to monitor regional weather records, review environmental indicators, and assess agricultural risk alerts.

5.3 Policy Maker Dashboard

Provides regional monitoring, historical weather information, and key indicators to support agricultural planning and policy-related decision-making.

5.4 Administrator Dashboard

Supports system administration and user account management, including the creation and management of user accounts.

8. Geographic Coverage

The current implementation includes three selected locations in Tanzania:

- Mbeya Region
- Kongwa District, Dodoma Region
- Mjini Magharibi, Zanzibar

9. Target Users

- Smallholder maize farmers
- Agricultural extension officers
- Agricultural policymakers
- System administrators
